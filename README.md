# Monifactory Dumper

A project that runs [Monifactory](https://github.com/Omicron-Industries/Monifactory), extracts read-only information, and closes the game.
Useful for analysis tools:
- using recipes for process line flowcharts;
- quest book pages, to present the quest book outside the game;
- you get the idea.

This is also the home of the [Monifactory Discord Bot](./integrations/discord/README.md).

## Requirements
Java 17, latest [Deno](https://deno.com/).
