A java agent to control the clock that animations read. The renderer freezes it at a chosen time around each draw, so every animated frame is a function of the frame index.

`FakeTime` is the API: `freeze(millis)` / `release()` around a draw, `holdAtlas(true)` once, then `tickAtlas(textureManager::tick)` once per frame. Only the freezing thread sees the fake time. Everything else in the game keeps the real clock. `record(recorder)` reports what the frozen thread reads and draws to a `FakeTime.Recorder`, so a renderer can tell from one draw whether it can look different at another time.

`ClockAgent` is the `-javaagent`. It rewrites `System.currentTimeMillis()` call sites in every class whose module can read this one, the return values of `Util.getMillis()` and `Level.getGameTime()`/`getDayTime()`, and puts a gate on `TextureManager.tick()`. For the recorder it also rewrites `System.nanoTime()` call sites (real time, reported) and adds a call on entry to a few Minecraft methods: the unfrozen clocks, `BufferUploader.upload`, `GlStateManager._drawElements`, `Font.drawInBatch` and `ItemRenderer.render`. There is no list of mods or mod classes. It prints what it patched when the game exits, and names any hook whose method it never found.
